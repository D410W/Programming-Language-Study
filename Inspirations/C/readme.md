### Principles

- Low-level access to memory
- Low-level system control
- Efficiency
- Minimalism

### Features

- Any expression can be a statement
- Pointers provide for machine-independent address arithmetic
- Common control-flow constructions (if-else, switch, while, for, do, break)
- Inline assembly

### Doesn't have

(will look into later)

- Multiprogramming
- Parallel operations
- Synchronization
- Coroutines
